# 🏦 Bank Management System in C

## Project Overview

The **Bank Management System** is a menu-driven application developed using the C programming language as a first-semester BCA Data Science mini project.

The project is designed to perform basic banking operations such as creating customer accounts, depositing money, withdrawing money, checking account balances, searching for accounts, displaying customer records, and transferring money between accounts.

It uses fundamental C programming concepts to demonstrate how programming can be applied to a real-world banking scenario.

## Features

- Create a new bank account
- Deposit money into an account
- Withdraw money from an account
- Check account balance
- Search customer account details
- Display all registered accounts
- Transfer money between accounts
- Save account records using file handling

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Compile the program:

   `gcc bank.c -o bank`

5. Run the program:

   `./bank`

## Project Purpose

The main objective of this project is to understand and implement basic C programming concepts through a practical application. It also helps develop logical thinking, problem-solving skills, and an understanding of how banking operations work.
